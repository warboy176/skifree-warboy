# Skier Game

A simple skier game implemented in JavaScript using HTML5 Canvas.

## How to Run

1. Open `index.html` in a web browser.

## Controls

- Left Arrow Key: Move left
- Right Arrow Key: Move right
- Spacebar: Jump

## Game Features

- Player movement with lane changing
- Jumping mechanic
- Randomly generated obstacles
- Collision detection
- Game states (Menu, Playing, Game Over)

## Files

- `index.html`: HTML structure and canvas setup
- `main.js`: Main game logic and loop
- `player.js`: Player class and logic
