# Skier Game

A simple skier game built with HTML5 Canvas and JavaScript.

## How to Run the Game

To run the game, open `index.html` in a web browser.

> Note: For local development, you may need to serve the files via a local server (e.g., using Python's built-in server).

## Game Controls

- Use the **left and right arrow keys** to move your skier.

## Game Features

- Player skier controlled by keyboard input
- Randomly generated NPC skiers
- Score tracking
- Collision detection
- Game over screen

## Files

- `index.html` - Main HTML file
- `style.css` - CSS styling
- `game.js` - Game logic and rendering
